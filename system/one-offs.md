# One-offs — exceptions to the normal week

This is where anything **out of the ordinary** lives so the controller knows about it. There's no live calendar connection — the system runs on this file + reasoning + the logs (git is the memory). So whenever something breaks the usual pattern, **tell Claude and it gets written here.** The 22:00 nightly brief and the 07:00 wake brief both read this file first and let anything here **override the default weekly schedule.**

## What counts as a one-off
Early start, day off work, moved golf tee time, a dentist/appointment, a night at your girlfriend's instead of Dad's, travelling, illness, a ref game time for the weekend, a skipped gym you'll make up — anything that isn't the standard week.

## How to use it
Just message Claude in plain English ("early start Tuesday, need to leave at 8", "golf's at 2pm Friday", "away this weekend"). Claude adds a dated line below and, once the date has passed, clears it out so the file stays short and current.

## Format
```
- YYYY-MM-DD (Day) — what's different · what it changes (wake/leave/movement/plans)
```

## Active one-offs
- **2026-08-07 (Fri)** — ⛳ Golf 18 holes in the morning (confirmed on). Big steps day; no gym (legs done Thu). Weather permitting.
- **2026-08-08 (Sat)** — ⚽ football game **14:45** · movement = football (leave time TBD — need travel time for a leave nudge).
- **2026-08-09 (Sun)** — ⚽ football game, **time TBC** · movement = football (confirm time when known).
- **Week note (w/c Mon 2026-08-04):** This week is Thu **gym (done)** + Fri **golf** + Sat/Sun **football** — so just the one gym session, and that's fine (golf + 2 matches = plenty of load). Don't push a 2nd/3rd gym this week; prioritise recovery for the games. Next gym (next week) = **B (Upper Push)**.
