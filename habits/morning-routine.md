# Morning Routine — 7:00 to 8:30 (work days)

Goal: get the most out of the morning — everything done, unrushed, out the door by 8:30 for a 9:00 start (30-min drive). This is the plan Claude leads every morning message with. **Nothing is too small to be on the list** — if it's part of the morning, it's written here.

## 🌙 Night-before prep (do it at wind-down — this is the real secret)
Half the morning chaos is solved the night before. At ~22:45:
- [ ] Iron & lay out tomorrow's clothes
- [ ] Pack the work bag
- [ ] Set out walk/run kit + trainers by the door
- [ ] Fill the water bottle, set it out

*(The disaster morning happened partly because none of this was ready. 5 minutes at night buys you a calm morning.)*

## ⏱️ The work-day timeline (Mon / Tue / Wed)
| Time | Action |
|------|--------|
| **7:00** | Up — no snooze. Big glass of water. Daylight/curtains open. |
| **7:05–7:35** | 🚶 Walk / run (mostly a walk; run only 1–2×/week) |
| **7:35–7:40** | 🧍 Posture stretches — the daily 4 (`appearance/posture-stretches.md`) |
| **7:40–7:57** | 🚿 Shower + shave + wash face |
| **7:57–8:10** | 🥣 Porridge — make + eat (45g oats, big bowl, 70% power) |
| **8:10–8:22** | 💈 Grooming + get dressed + pack (full checklist below) |
| **8:22–8:30** | 🎥 Film the day's clip · stand tall · phone/keys/wallet · leave |

## ✅ The full checklist (tick every one — nothing's too small)
**Wake & body**
- [ ] Up at 7:00, no snooze
- [ ] ⚖️ Weigh-in — log it in **MacroFactor** (weight + nutrition live there, not in this repo). Same time each morning, before food/water, for a clean trend.
- [ ] Big glass of water, curtains/daylight open
- [ ] Move — the morning walk is the **default**; if you've got a run, gym or match later, **that's your move, skip the walk** (one session counts, no need to double up)
- [ ] 🧍 Posture stretches — the daily 4 (chin tucks, doorway chest, thoracic extension, wall angels)

**Wash & groom**
- [ ] Shower
- [ ] Shave (or shape the stubble/beard deliberately)
- [ ] Wash face — cleanser
- [ ] Moisturise
- [ ] SPF moisturiser (daytime — the #1 thing for your skin long-term)
- [ ] Brush teeth (+ floss)
- [ ] Deodorant
- [ ] Hair styled/tidy

**Fuel & out the door**
- [ ] Porridge + protein
- [ ] Dressed in clean clothes that fit
- [ ] Bag packed (already done last night — just grab it)
- [ ] Film the day's clip
- [ ] Stand tall — shoulders back
- [ ] Phone, keys, wallet, water bottle
- [ ] Leave by 8:30

## Rules for the morning
- **No phone scrolling until you've moved.** (Social's blocked till 9 anyway.)
- **Protect the leave time above all.** If something eats time — nosebleed, boiler, whatever — drop the *least* important thing (usually the run), never the 8:30 departure. Getting to work on time is the non-negotiable.
- **Two-minute version of any step still counts.** Rushed? Chin tucks instead of the full 4; cleanse + SPF even if you skip the rest. The streak matters more than the size.
- **Never miss twice:** a chaos morning is fine; just don't let it become tomorrow's lie-in.

## Gym-day mornings (Thu / Sat / Sun)
Different shape — no work, gym is at 9:00. Roughly: 7:00 up + water → posture stretches → light breakfast/pre-gym rice cake → 9:00 gym (Workout A/B) → shower + full grooming + breakfast after. The walk is optional those days (the gym is the move), but still do the grooming checklist — just shifted to after the gym.
