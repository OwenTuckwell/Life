# Daily System

The non-negotiables. Keep this list SHORT. A short list you do every day beats a long list you abandon by Wednesday.

## Daily non-negotiables (starter set — we'll tune to you)
- [ ] **Move** — training session *or* a 20-min walk minimum. Something, every day.
- [ ] **Protein + water** — a protein source at each meal, water bottle filled and finished.
- [ ] **Skill block** — 20–30 min on the one skill you're building.
- [ ] **Tidy 5** — 5 minutes tidying yourself/your space (shower, groom, clear a surface). Small, but it changes how you feel.
- [ ] **Lights out on time** — sleep is the keystone. Pick a bedtime and defend it.

## The rules of the system
- **Two-minute version exists for every habit.** No time/energy? Do the tiny version (one push-up, one page, one minute). The streak matters more than the size.
- **Never miss twice.** Bad day? Fine. Just don't let it become two.
- **Stack habits onto anchors.** "After I brush my teeth, I do my skill block." Attach the new thing to something you already always do.
- **Make it obvious, make it easy.** Lay out gym clothes the night before. Put the guitar/book/whatever where you'll trip over it.

## Weekly rhythm
- **Mon–Fri:** run the daily system.
- **Sat:** lighter / active recovery / catch-up.
- **Sun:** weekly review (`reviews/weekly-review-template.md`) + plan the week.
